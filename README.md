# 国科大模拟选课系统

> 先排时间，再做选择。把“这门课能不能选”变成“这门课和我的课表合不合得来”。

这是一个面向中国科学院大学选课场景的离线模拟选课网页。它把课程检索、已选课程、学期课表和按时间推荐放在同一个工作台里，让你在真正提交选课之前，先把自己的方案排一遍、撞一遍、存一遍。

## 为什么做它

国科大官方选课系统在实际使用中有两个很容易让人头疼的场景：

1. 课程列表不方便直观看出时间冲突；
2. 已经知道“周三 1-4 节有空”，却很难反过来查出这段时间还能选什么。

本项目参考了小红书博主“耳总”的设计思路，正是为了解决这两个问题：把课程时间放进课表，把空闲时间变成检索条件，把冲突原因直接写在推荐卡片上。

## 这个页面能做什么

| 模块 | 用途 |
| --- | --- |
| 课程检索 | 按课程号、课程名、教师、类别、考核方式等条件筛选课程 |
| 已选课程 | 管理当前方案，查看课程号、教师、上课时间和考核方式，并标记专业类学位课 |
| 学期课表 | 按教学周查看完整安排；点击课表即可选定待查询时间段 |
| 按上课时间推荐 | 选择星期、节次和可选周号，优先展示不冲突课程，再展示冲突课程及原因 |
| 暂存存档 | 保存多个选课方案，之后可以读取、更新或另存为新方案 |

页面顶部还会实时汇总学分进度、专业类课程和学位课进度，以及闭卷、开卷、大开卷、读书报告等考核方式分布，方便快速检查本学期的整体安排。

## 推荐的使用方式

1. 先在“课程检索”里用筛选器缩小范围，查看课程号、教师和考核方式。
2. 把想比较的课程加入“已选课程”，系统会同步更新课表和学分统计。
3. 在左侧课表点击一段空闲时间，或在右侧手动选择星期与节次；蓝色框就是当前查询时间段。
4. 在“按上课时间推荐”里查看结果：不冲突课程排在前面，冲突课程会标红，并说明冲突课程及重叠教学周。
5. 形成阶段性方案后点击“更新/保存”，可更新当前存档，也可保存为新的存档名称。

## 开始使用

本项目是单文件离线网页，不需要安装依赖，也不需要后端服务。

```text
双击 index.html
```

或者使用任意静态文件服务器打开项目目录。课程数据内嵌在页面中，适合用来做选课规划、时间冲突检查和方案比较。
