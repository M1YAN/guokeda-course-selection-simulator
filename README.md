# 国科大模拟选课系统

这是一个面向中国科学院大学选课场景的离线模拟选课网页。

## 项目目的

本项目参考了小红书博主“耳总”的设计思路，主要用于解决国科大选课系统中不方便直观看到课程时间冲突，以及无法根据指定上课时间段查看可选择课程的问题。

## 主要功能

- 课程检索与多条件筛选
- 已选课程管理、专业类课程学位课标记
- 按教学周查看学期课表
- 按星期和节次推荐可选课程
- 推荐课程冲突提示与冲突教学周说明
- 暂存存档、读取和更新选课方案
- GitHub Pages 在线访问

## 说明

本项目仅供学习、规划和选课时间安排参考，不代表学校官方选课结果。课程数据为内嵌示例数据，请以学校官方系统和通知为准。
